# Phase 0 Cleanup Summary — Repo Structure & Organization

This document records all file movements, renames, merges, and deletions executed during Phase 0 of the EventTrail / CampusPulse repository cleanup.

---

## 1. Merged & Deleted Files

| Original File(s) | Action Taken | Target / New Location | Rationale |
|---|---|---|---|
| `map.md`<br>`map (1).md` | **Merged & Deleted** | `/docs/campus-navigation.md` | Both files were duplicate/near-duplicate planning and build guides for campus navigation. `map.md` covered Method 2 walkway graph pathfinding and GeoJSON generation, while `map (1).md` covered the progressive 4-mode MapLibre UI build guide. They have been consolidated into a single canonical reference document in `/docs/campus-navigation.md`. |
| `/brain/65601a32-.../scratch/*.js` | **Deleted** | *Removed* | The `/brain` folder at the root contained temporary scratch scripts (`inspect_content.js` and `parse_didasko.js`) generated by a previous agent run. These were not part of the application and have been purged. |

## 3. Established Directories

| Directory | Purpose |
|---|---|
| `/src` | Application frontend source code (React + Vite + Tailwind). Behavior and visual design remain unchanged. |
| `/docs` | Central repository for all documentation, architecture specifications, build plans, and progressive module completion reports (`/docs/modules/`). |
| `/infra` | Dedicated home for AWS serverless Infrastructure as Code (CDK) and deployment scripts, which will be populated starting in Module 1. |

## 4. Verification

- All application source files in `/src` remain untouched in logic and behavior.
- No frontend components or routes were modified.
- Root directory is now clean, containing only configuration files (`package.json`, `vite.config.js`, `.gitignore`, `tailwind.config.js`, `vercel.json`, etc.) and the canonical `README.md`.
